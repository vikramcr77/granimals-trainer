# Granimals Trainer

A personal workout tracking web app built for Vikram's Week 14 rehab-to-strength programme.

## Features
- **Program preloaded** — Push / Pull / Posterior Chain / Core split + Warm-Up & Cool-Down, with exact sets, reps and durations.
- **Log workouts** — reps × weight per set, add/remove sets, auto-saves as you go (drafts survive closing the app).
- **Timers** — countdown timers for every timed move + rest timers between sets, with 3-2-1 tick and end alarm.
- **Inline tutorial videos** — verified form videos (physio-credited where possible) that play inside the app.
- **Progress** — training-volume chart, personal records, and full history grouped by month & filterable by date.
- **Session history navigation** — page back/forward through previous sessions to compare and track progress.
- **Goals** — weekly-session & bodyweight targets, plus progressive-overload next-lift suggestions.
- Crimson & Steel theme, light/dark, saves to your device (localStorage).

Single self-contained `index.html` — no build step.
